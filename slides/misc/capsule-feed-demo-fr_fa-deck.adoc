== مقدمه

[%step]
* نمایش خط لوله اسلایدر → کپسول
* تولید اسکریپت کپسول از یادداشت‌های گوینده
* قرارداد متن ساده‌ای که توسط capsule-gradle مصرف می‌شود

[NOTE.speaker]
--
به این نمایش خط لوله فید کپسول خوش آمدید.
در اینجا می‌بینیم چگونه slider‑gradle یادداشت‌های گوینده را استخراج می‌کند
از یک دک AsciiDoc برای تولید اسکریپتی که توسط capsule‑gradle مصرف می‌شود.
--

[.slide,data-transition="slide"]
== قرارداد capsule-gradle

[%step]
* قالب متن سادهٔ تعیین‌شده
* سرصفحه: `=== CAPSULE SCRIPT : nom ===`
* یک بخش برای هر اسلاید: `--- SLIDE n : titre ---`
* بدنه: یادداشت گوینده به همان شکل

[NOTE.speaker]
--
قرارداد بین اسلایدر و کپسول عمداً ساده است :
یک فایل متنی با یک سرصفحه و یک بخش برای هر اسلاید.
هر بخش شامل یادداشت گوینده است که به گفتار متن به‌صورت TTS تبدیل می‌شود.
--

[.slide,data-transition="slide"]
== اعتبارسنجی دورگرد

[%step]
* پارسِر بخش‌ها را از AsciiDoc استخراج می‌کند
* نویسنده (writer) به قالب متن سادهٔ قرارداد سریالیزه می‌کند
* capsule-gradle این قالب را دوباره پارس می‌کند
* بدون اتلاف : آنچه اسلایدر می‌نویسد، کپسول می‌خواند

[NOTE.speaker]
--
دورگرد معتبر است : پارسِر بخش‌ها را از منبع AsciiDoc استخراج می‌کند،
writer آن‌ها را به قرارداد متن ساده سریالیزه می‌کند،
و capsule‑gradle همان قالب را بدون هیچ گونه از دست رفتن داده‌ای دوباره پارس می‌کند.
--

[.slide,data-transition="slide"]
== نتیجه‌گیری

[%step]
* فید کپسول = استخراج یادداشت‌های گوینده
* بدون JSON، بدون اسکرین‌شات در قرارداد
* اسکرین‌شات‌ها به‌صورت زنده توسط capsule‑gradle گرفته می‌شوند
* اسلایدر اسکریپت را تولید می‌کند، کپسول آن را مصرف می‌کند

[NOTE.speaker]
--
برای جمع‌بندی : فید کپسول صرفاً استخراج یادداشت‌های گوینده است.
بدون JSON، بدون اسکرین‌شات در قرارداد — اسکرین‌شات‌ها به‌صورت زنده توسط
capsule‑gradle در طول تولید ویدیو گرفته می‌شوند. اسلایدر اسکریپت را
تولید می‌کند، کپسول آن را مصرف می‌کند. مرز تولید‑مصرف‌کننده به‌صورت صحیح حفظ می‌شود.
--

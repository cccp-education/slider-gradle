== Kontrak capsule-gradle

[%step]
* Format teks biasa yang spesifik
* Header: `=== CAPSULE SCRIPT : name ===`
* Satu bagian per slide: `--- SLIDE n : title ---`
* Body: Catatan pembicara apa adanya

[NOTE.speaker]
--
Kontrak antara slider dan capsule sengaja dibuat sederhana:
sebuah file teks dengan header dan satu bagian per slide.
Setiap bagian berisi catatan pembicara yang akan menjadi narasi suara.
--

== Verifikasi Bolak-Balik (Round-trip)

[%step]
* Parser mengekstrak bagian dari AsciiDoc
* Writer menserialisasi ke kontrak teks biasa
* capsule-gradle menganalisis ulang format yang sama
* Nol kehilangan data: apa yang ditulis slider dibaca oleh capsule

[NOTE.speaker]

Verifikasi bolak-balik telah dilakukan: parser mengekstrak bagian dari sumber AsciiDoc,
writer menserialisasikannya kembali ke kontrak teks biasa,
dan capsule-gradle menganalisis ulang format yang sama persis tanpa ada kehilangan data.

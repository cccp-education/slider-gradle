[%step]

欢迎来到 capsule feed 管道的演示。

生成供 capsule-gradle 消费的文本。
--

[.slide,data-transition="slide"]
== capsule-gradle 节点

[%step]
* 指定的普通文本格式
* 头部: `=== CAPSULE SCRIPT : name ===`
* 每张幻灯片一个段落: `--- SLIDE n : title ---`
* 正文: 演讲者备注原样

[NOTE.speaker]
--
slider 与 capsule 之间的节点故意保持简单：
一个包含头部和每张幻灯片一个段落的文本文件。
每个段落包含演讲者备注，成为语音叙述。
--

[.slide,data-transition="slide"]
== 往返验证

[%step]
* 解析器从 AsciiDoc 中提取段落
* 编写器序列化为普通文本节点
* capsule-gradle 重新解析相同的格式
* 零丢失：slider 写的内容 capsule 能读取

[NOTE.speaker]
--
往返已验证：解析器从 AsciiDoc 源提取段落，
编写器再将其序列化回普通文本节点，
并且 capsule-gradle 完全重新解析相同的格式，且没有任何数据丢失。
--

[.slide,data-transition="slide"]
== 结论

[%step]
* capsule feed = 提取演讲者备注
* 节点中没有 JSON 也没有截图
* 截图直接由 capsule-gradle 捕获
* slider 生成文本，capsule 消费它

[NOTE.speaker]
--
总结：capsule feed 简单地提取演讲者备注。
节点中没有 JSON 也没有截图——截图在生成视频时由 capsule-gradle 直接捕获。
slider 生成文本，capsule 消费它。产品与消费者之间有明确的边界。

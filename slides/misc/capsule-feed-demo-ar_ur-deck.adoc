== تعارف

[%step]
* سلائیڈر سے کیپسول تک پائپ لائن کی پیشکش
* مقرر کے نوٹس سے کیپسول متن تیار کرنا
* ایک عام ٹیکسٹ نوڈ جسے کیپسول-گریڈل استعمال کرتا ہے

[NOTE.speaker]
--
آپ سب کو کیپسول فیڈ پائپ لائن کے اس ڈیمونسٹریشن میں خوش آمدید۔ ہم دیکھیں گے کہ سلائیڈر-گریڈل کیسے مقرر کے نوٹس کو AsciiDoc پریزنٹیشن سے نکالتا ہے تاکہ ایک متن تیار ہو جو کیپسول-گریڈل استعمال کرے۔
--

[.slide,data-transition="slide"]
== کیپسول-گریڈل کا نوڈ

[%step]
* مخصوص سادہ ٹیکسٹ فارمیٹ
* ہیڈر: `=== CAPSULE SCRIPT : name ===`
* ہر سلائیڈ کے لیے ایک سیکشن: `--- SLIDE n : title ---`
* باڈی: مقرر کا نوٹ جیسا ہے

[NOTE.speaker]
--
سلائیڈر اور کیپسول کے درمیان نوڈ جان بوجھ کر سادہ رکھا گیا ہے: ایک ٹیکسٹ فائل جس میں ہیڈر اور ہر سلائیڈ کے لیے ایک سیکشن ہوتا ہے۔ ہر سیکشن میں مقرر کا نوٹ شامل ہوتا ہے جو آڈیو نیریشن بن جاتا ہے۔
--

[.slide,data-transition="slide"]
== واپسی کی توثیق

[%step]
* پارسر AsciiDoc سے سیکشنز نکالتا ہے
* لکھنے والا اسے دوبارہ سادہ ٹیکسٹ نوڈ میں ترتیب دیتا ہے
* کیپسول-گریڈل اسی فارمیٹ کو دوبارہ پارس کرتا ہے
* زیرو ڈیٹا لوس: جو سلائیڈر لکھتا ہے، وہی کیپسول پڑھتا ہے

[NOTE.speaker]
--
واپسی کی توثیق مکمل ہو چکی ہے: پارسر AsciiDoc سورس سے سیکشنز نکالتا ہے، لکھنے والا انہیں دوبارہ سادہ ٹیکسٹ نوڈ میں ترتیب دیتا ہے، اور کیپسول-گریڈل بالکل اسی فارمیٹ کو بغیر کسی ڈیٹا کے نقصان کے دوبارہ پارس کرتا ہے۔
--

[.slide,data-transition="slide"]
== نتیجہ

[%step]
* کیپسول فیڈ = مقرر کے نوٹس کا استخراج
* نوڈ میں نہ JSON ہے نہ اسکرین شاٹس
* اسکرین شاٹس براہ راست کیپسول-گریڈل کے ذریعے لیے جاتے ہیں
* سلائیڈر متن تیار کرتا ہے اور کیپسول اسے استعمال کرتا ہے

[NOTE.speaker]
--
اختتام کے طور پر: کیپسول فیڈ صرف مقرر کے نوٹس کا استخراج ہے۔ نوڈ میں نہ تو JSON ہے اور نہ اسکرین شاٹس — اسکرین شاٹس براہ راست کیپسول-گریڈل کے ذریعے ویڈیو تیار کرتے وقت لیے جاتے ہیں۔ سلائیڈر متن تیار کرتا ہے اور کیپسول اسے استعمال کرتا ہے۔ پیدا کرنے والے اور استعمال کرنے والے کے درمیان واضح حد ہے۔

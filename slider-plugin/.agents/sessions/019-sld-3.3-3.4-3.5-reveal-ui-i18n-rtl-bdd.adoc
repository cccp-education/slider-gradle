== DDD Architecture

New bounded context `slider.i18n` (Reveal.js UI i18n):
- Domain: RevealUiMessages (value object), RevealUiNavMessages, RevealUiControlsMessages
- Catalog: RevealUiMessageCatalog (factory, 10 languages single source of truth)
- Service: RevealUiMessagesWriter (JS file generation, pure function)
- Resolver: RevealRtlResolver (RTL decision from LanguageCatalog)
- Task: generateRevealUiMessages (Gradle task, delegates to writer)

Pattern aligned on bakery BKY-I18N (config cascade, MessageBundle, LocaleResolver).
i18n-contracts N0 consumed (LanguageCatalog, SupportedLanguage).

== US livrées

=== US-1 — Guard plan vide pipeline traduction

Crash `DeckTranslator` sur plan vide (tous les targets = langue source).

- **`TranslationOutcome.kt`** : `require(results.isNotEmpty())` supprimé.
  Constante `TranslationOutcome.EMPTY` + `of()` retourne `EMPTY` si liste vide
  (duplicate check conservé).
- **`DeckTranslator.kt`** : guard `if (plan.tasks.isEmpty()) return TranslationOutcome.EMPTY`.
- **`TranslateDeckTask.kt`** : guard avant résolution LLM (`project.aiProvider`) —
  `logger.lifecycle(task.translateDeck.noTargets)` puis return. Aucun appel réseau.
- **i18n** : clé `task.translateDeck.noTargets=` ajoutée après
  `task.translateDeck.summary=` dans 11 fichiers Messages_*.properties (traductions
  vérifiées, format `{0}`).
- **Tests 3 niveaux** :
  - 2 unit : `TranslationOutcomeTest` (accept-empty) + `DeckTranslatorTest` (empty-plan)
  - 1 functional : `TranslateDeckFunctionalTest` guard — `-Ptarget.languages=fr` sur
    deck fr → build SUCCESS, message noTargets, zéro fichier généré. Fixture
    `fixtures/decks/` (hors `slides/` pour éviter l'écrasement scaffold), chemins absolus.
  - 2 scénarios Cucumber `13_deck_translation.feature` : plan vide (0 tasks) +
    outcome vide all-translated.

=== US-2 — Regex `buildOutputFile` uppercase

- **`DeckTranslator.kt`** : `Regex("_[a-z]{2}$")` → `Regex("_[a-zA-Z]{2}$")` —
  le segment langue uppercase (`_ZH`) n'était pas détecté → double suffixe.
- 1 unit test RED→GREEN : `kotlin-coroutines_ZH-deck.adoc` → `kotlin-coroutines_en-deck.adoc`.

=== US-3 — SSL propriétés système scopées

- **`RagManager.kt`** `buildStore` : `System.setProperty("ssl"/"sslmode")` global
  remplacé par un try/finally avec `restoreSystemProperty` (restaure la valeur
  précédente ou efface si absente). Le builder capture les valeurs avant la
  restauration, donc le comportement est identique mais la JVM n'est plus mutée
  globalement.
- Zéro test modifié (comportement identique).

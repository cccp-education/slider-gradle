= Session 029 — EPIC SLD-5 Deck Translation Pipeline (US-5.0 → US-5.5)
:date: 2026-07-13
:session: 029

== Objectif

Démarrer et implémenter l'EPIC SLD-5 — Deck Translation Pipeline. Pipeline de
traduction de deck one-to-many : partant d'un deck source (deck-context.yml +
.adoc) dans une langue, génère les 10 variantes localisées couvrant le top 10
des langues les plus parlées (source : `10 langues les plus parlés.csv` —
aligné sur `LanguageCatalog.supportedCodes()` : en, zh, hi, es, fr, ar, bn, pt,
ru, ur).

SLD-5 est le chaînon manquant du story i18n : SLD-3 a posé l'infra (cascade 5
couches, TranslatorManager 10 langues, Reveal.js UI i18n, RTL), SLD-5 rend la
traduction de deck opérationnelle.

== Méthode

Baby-step TDD/BDD — RED → GREEN → REFACTOR. Trois niveaux de tests par US :
unit (value object pur) → functional (GradleTestKit) → cucumber (BDD
end-to-end). English only dans le code, Gherkin, commentaires. DDD : value
objects purs + adaptateur LLM + tâche Gradle thin (pattern `slider.repository`
/ `slider.capsule`).

== Domaine DDD `slider.translation` (nouveau)

6 fichiers production dans `slider/translation/` :

. `TranslationRequest.kt` — value object : source DeckContext + targetLanguages
  validée contre `LanguageCatalog.supportedCodes()`. Refus : langue source
  invalide, liste cible vide, code inconnu, doublons.
. `DeckTranslationPlan.kt` — value object : expand request en list de
  `TranslationTask` (from → to + sourceDeck). Filtre identity (source → source).
. `TranslationResult.kt` — sealed class 3 variants : Translated (deck + adoc),
  Skipped (reason), Failed (errorMessage). Chaque variant expose targetLanguage
  + status.
. `TranslationOutcome.kt` — agrégation : translatedCount/skippedCount/failedCount,
  translatedResults(), failures(), translatedLanguages(), isAllTranslated(),
  summary(). Refus liste vide + doublons target languages.
. `LanguageModelAdapter.kt` — port (interface DDD hexagonal) : translate(deck,
  adoc, from, to) → String?. Le domaine ne dépend jamais de langchain4j.
. `DeckTranslator.kt` — domain service : orchestre LLM par langue cible via le
  port. Produit TranslationOutcome. buildOutputFile : injecte `<lang>` dans le
  nom de fichier (`kotlin-deck.adoc` → `kotlin_en-deck.adoc`), remplace un
  segment `_<lang>` existant.
. `OllamaLanguageModelAdapter.kt` — adaptateur infrastructure : implémente le
  port avec langchain4j ChatModel. System prompt préserve syntaxe AsciiDoc +
  attributs Reveal.js, traduit uniquement le texte humain.
. `TranslateDeckTask.kt` — tâche Gradle `translateDeck` (group "translator",
  @DisableCachingByDefault). Inputs : `-Pdeck.context` + `-Pdeck.adoc` (optionnel)
  + `-Ptarget.languages` (défaut 10). Outputs : 10 × `_<lang>-deck-context.yml`
  + `_<lang>-deck.adoc` dans slides/misc/.

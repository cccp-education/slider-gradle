fiabiliser + tester le contrat `generateCapsule` existant (SliderManager.kt:775-838, inline

== Baby-step TDD/BDD (RED → GREEN → REFACTOR)

=== US-2.5a — Unit: CapsuleScript + SlideSegment + CapsuleScriptWriter

RED: `CapsuleScriptWriterTest.kt` (12 tests) — header deckName, segments count, note
placement, blank line separation, multi-line preservation, trim whitespace, immutabilité
invariants (deckName non-blank, title non-blank, speakerNote non-blank).

GREEN: `slider/capsule/CapsuleScript.kt` — `CapsuleScript` (aggregate root, deckName +
segments, `isEmpty`), `SlideSegment` (VO, index + title + speakerNote, invariants sur
title/speakerNote), `CapsuleScriptWriter` (objet, `write(script): String` sérialise au
format contrat `=== CAPSULE SCRIPT : X ===` + `--- SLIDE n : title ---`).

REFACTOR: invariants DDD au constructeur (aggregate invariant), `CapsuleScript.isEmpty`
pour decks sans notes, `CapsuleScriptWriter.write` rejette segments vides.

=== US-2.5b — Unit: AsciidocSpeakerNoteParser

RED: `AsciidocSpeakerNoteParserTest.kt` (11 tests) — extraction multi-slides, skip slides
sans `[NOTE.speaker]`, multi-lignes, attributes après bracket `[NOTE.speaker,style=foo]`,
attribute lines précédant heading `[.slide,...]`, level-2 only (pas `===`), reindexation
séquentielle par occurrence, blank deckName rejeté, empty deck sans notes.

GREEN: `slider/capsule/AsciidocSpeakerNoteParser.kt` — `parse(adocContent, deckName):
CapsuleScript`. Parser ligne-par-ligne : `== ` = slide heading, `[NOTE.speaker]` ou
`[NOTE.speaker,...]` démarre note, `--` ... `--` délimite le bloc. Reindexation 1-based
par ordre d'occurrence. Slides sans note = skippées.

Smoke: `CapsuleSmokeRealDeckTest.kt` — round-trip sur `kotlin-intro-deck.adoc` réel
(10 slides, 10 notes) → 10 segments, format contrat respecté.

=== US-2.5c — Functional: generateCapsule task refactor

GREEN: `SliderManager.kt:775-838` refactoré — `generateCapsule` délègue au domaine
(`AsciidocSpeakerNoteParser.parse` + `CapsuleScriptWriter.write`). Logique inline 60
lignes supprimée, remplacée par 12 lignes de délégation. `dependsOn("asciidoctor")`
supprimé (parser lit les `.adoc` sources, pas le rendu HTML — la dépendance était une
erreur de design). Group corrigé `generate`→`slider`. Log skip explicite pour decks sans
notes (`logger.lifecycle("⚠ ...")`).

RED: `GenerateCapsuleFunctionalTest.kt` (4 tests via GradleRunner) — task registered in
slider group, produit `<deck>-script.txt` conforme contrat, skip decks sans notes,
1-based slide indices. Validation `build/capsule/` output dir.

=== US-2.5d — Cucumber BDD: 9_capsule_feed.feature

RED→GREEN: `9_capsule_feed.feature` (9 scénarios initiaux EN) + `CapsuleFeedSteps.kt`
(15 step defs). Couvre : 1 segment, multi-segments ordre, skip sans note, contrat
plain-text (header + blank + SLIDE markers), multi-lignes, deck vide, blank deckName
rejeté, attributes après bracket, level-2 only.

Correction TDD : DataTable → doc string (Cucumber Java8 limitation avec
`List<Map<String,String>>`), step ambigu `{int} segment(s)` vs `{int} segments` résolu
(regex `(s)` optionnel ne match pas en Cucumber Java8, unification en `{int} segments`).

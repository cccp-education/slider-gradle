=== Premier essai — rejet namespace

`publishAggregationToCentralPortal` FAILED :
```
{"pkg:maven/slider.translator/slider.translator.gradle.plugin@0.0.8?type=pom":
 ["Namespace 'slider.translator' is not allowed"]}
```

Cause : le sous-plugin `slider.translator` (créé S-018) a un plugin ID qui
crée un namespace `slider.translator` non autorisé sur Central (seul
`education.cccp.*` est autorisé).

=== Correction — renommage plugin ID

| Fichier | Changement |
| `slider-plugin/slider/build.gradle.kts:130` | `id = "slider.translator"` → `id = "education.cccp.slider.translator"` |
| `slider-plugin/slider/src/functionalTest/kotlin/slider/TranslatorFunctionalTest.kt:20` | `id("slider.translator")` → `id("education.cccp.slider.translator")` |

Aucune autre référence dans `src/` (vérifié grep). Docs de gouvernance
(INDEX, SESSIONS_HISTORY, sessions/) non modifiées — référence historique
au plugin ID ancien conservée pour traçabilité.

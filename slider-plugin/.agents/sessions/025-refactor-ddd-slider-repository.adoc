== Méthodologie

Baby-step DDD/TDD/BDD respecté :
1. RED — test unit écrit en premier, compilation échoue
2. GREEN — code minimum pour faire passer le test
3. REFACTOR — délégation au domaine, suppression dead code
4. Functional — GradleTestKit valide l'intégration plugin
5. Cucumber BDD — feature Gherkin valide le comportement métier

Pattern DDD aligné sur domaines existants `slider.rtl` (S-021) et
`slider.capsule` (S-020) : value objects purs, sealed results, aucune
dépendance Gradle `Project` dans le domaine.

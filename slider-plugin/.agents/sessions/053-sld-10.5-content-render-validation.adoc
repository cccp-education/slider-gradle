== Objectif

Implémentation de l'US SLD-10.5 (Assertions Playwright enrichies) selon le
cadrage exhaustif de la session 052. L'US introduit la couche *adaptateur
Playwright* de l'EPIC SLD-10 : un snapshot enrichi `ContentRenderData` (DTO

`ContentPlaywrightAdapter` qui extrait le snapshot depuis une `Page` réelle.

== Décisions architecturales

. **Deux objects d'assertion coexistent** : `ContentSlideAssertion` (S-051,
  estimation a priori sur `SlideContent`+`SlideLayout`) et
  `ContentRenderAssertion` (S-053, mesure a posteriori sur
  `ContentRenderData`). Les 4 codes de `ContentAssertionCode` sont
  partagés. Justification : le pattern RTL n'a qu'un seul
  `RtlSlideAssertion` car il n'y a pas d'estimation a priori possible (le
  RTL est une propriété du rendu, pas du contenu). Pour le content,
  l'estimation a priori (avant rendu, sur le .adoc) et la mesure a
  posteriori (après rendu, sur le DOM) sont toutes deux utiles — d'où les
  deux objects.

. **`MIN_CONTRAST_RATIO = 4.5` vit sur `ContentRenderAssertion`** (pas sur
  `ContentSlideAssertion`). Justification : le contraste WCAG n'est
  mesurable qu'après rendu (couleurs résolues par le CSS). SLD-10.4
  utilisait le ratio `titleFontSize/bodyFontSize` comme heuristique de
  contraste — c'était un proxy. SLD-10.5 le remplace par la vraie mesure
  WCAG.

. **Port 4337** pour le functional test content. Justification : éviter
  collision avec LTR 4335 (`SliderPlaywrightE2eTest`) et RTL 4336
  (`RtlPlaywrightFunctionalTest`). Audit cross-borough confirmé : aucun
  borough n'utilise 4337.

. **`bypassInvariants` paramètre privé** sur `ContentRenderData`. La
  factory `EMPTY` bypass les invariants `init` via un paramètre privé
  `bypassInvariants: Boolean = false`. Justification : les tests Cucumber
  construisent le snapshot progressivement (EMPTY puis copy), les
  invariants ne s'appliquent qu'aux instances construites hors factory.

. **Pas de Cucumber dans SLD-10.5**. Le BDD end-to-end (validation a
  priori + a posteriori) est couvert par SLD-10.6 (US séparée, à planifier).

. **Pas de gating `assumeTrue`**. Le functional test échoue explicitement
  si la fixture est absente (message d'aide pointant vers
  `./gradlew generatePlaywrightFixtures`). Pattern aligné sur
  `RtlPlaywrightFunctionalTest` (S-021).

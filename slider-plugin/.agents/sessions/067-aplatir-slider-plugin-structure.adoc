== Résumé

Le dossier `slider-plugin/slider/` (sous-projet Gradle déclaré par
`include("slider")` dans `slider-plugin/settings.gradle.kts`) était une
déviation du contrat d'architecture « Plugin Indépendant + Racine
Consommateur » (article 0124) : `{name}-plugin/` doit être un build
autonome avec `src/` à sa racine et **zéro `include()` / zéro sous-projet**.

slider-gradle était le **seul borough** avec cette indirection
(`slider-plugin/slider/src/` au lieu de `slider-plugin/src/`). Tous les
autres suivent le pattern (bakery-plugin/src, codex-plugin/src,
planner-plugin/src, capsule-plugin/src, document-plugin/src).

Héritage du tout premier commit (`d3aacdd "Once Upon A Time..."`) : le
sous-projet a été copié depuis une source `include("module")` (le commit
initial contient d'ailleurs `com/cheroliv/bakery`). L'indirection n'a
jamais été aplatie depuis.

Fix : aplatissement complet de `slider-plugin/slider/` vers
`slider-plugin/`, via `git mv` (historique préservé — rename detection,
211 fichiers déplacés).

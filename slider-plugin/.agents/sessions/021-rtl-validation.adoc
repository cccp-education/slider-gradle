== Ce que le test a révélé

Le premier run functional a trouvé un vrai écart de connaissance :
Reveal.js gère le RTL via `rtl: true` dans la config JS + une classe `.rtl`
sur `.reveal` au runtime, **pas** via `<html dir="rtl">` ni `text-align: right`.
Les assertions initiales (basées sur des hypothèses HTML standards) ont été
adaptées pour matcher le modèle réel de Reveal.js. C'est exactement le type
de problème que la validation visuelle Playwright devait révéler.

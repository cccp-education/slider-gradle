== Contexte

Le slider-gradle n'avait pas d'i18n de plugin UI (descriptions de tâches, logs).
Les boroughs plantuml-gradle, bakery-gradle et document-gradle ont déjà leur
propre système d'i18n. Le pattern plantuml-gradle (ResourceBundle UTF-8 +
Messages_{code}.properties) est le gold standard pour l'i18n de plugin Gradle UI.

== Travail réalisé

=== SliderMessages.kt — singleton i18n
- `slider/i18n/SliderMessages.kt` : singleton ResourceBundle UTF-8 (pattern PlantumlMessages)
- `get(key, lang)` pour chaînes simples
- `format(key, lang, args...)` pour chaînes paramétrées (MessageFormat)
- `resolveLanguage(project)` : cascade CLI `-Planguage` > gradle.properties > DSL > default "en"
- 10 langues supportées : en, zh, hi, es, fr, ar, bn, pt, ru, ur

=== 11 fichiers Messages_*.properties
- `src/main/resources/i18n/Messages.properties` (base/fallback EN)
- `Messages_en.properties` (EN explicite)
- `Messages_fr.properties` (FR)
- `Messages_zh.properties` (中文)
- `Messages_hi.properties` (हिन्दी)
- `Messages_es.properties` (Español)
- `Messages_ar.properties` (العربية)
- `Messages_bn.properties` (বাংলা)
- `Messages_pt.properties` (Português)
- `Messages_ru.properties` (Русский)
- `Messages_ur.properties` (اردو)

=== Câblage dans tous les registrars
- `RevealJsTaskRegistrar` : cleanBuild, asciidoctorRevealJs, generateDashboard
- `PlaywrightTaskRegistrar` : serveSlides, installPlaywright, visualTest

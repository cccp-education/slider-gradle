== Décisions

. **Mock-LLM fallback** : `resolveModel` détecte `-Pollama.baseUrl` et
  fallback sur `createOllamaChatModel` legacy. Préserve les 9 scénarios
  Cucumber `01_propose_deck_context` qui injectent un mock HTTP. En
  production (pas de `-Pollama.baseUrl`), `LlmBuildService` est utilisé.
  Ce fallback sera supprimé quand les tests Cucumber migreront vers un
  mock `LlmBuildService` (future US).
. **TranslatorManager déprécié conservé** : utilise encore
  `createOllamaChatModel`/`localModels`/`generateStreamingResponse`.
  Expulsion future EPIC SLD-CR4 (suppression `TranslatorManager` +
  `TranslatorPlugin` + 2 tests + 1 feature Cucumber).
. **DI native Gradle (Decision 001)** : `BuildService<Params>` +
  `Provider<T>`, pas de conteneur DI. `LlmBuildService` enregistré une
  fois par build, shared par RAG tasks + TranslateDeckTask.
. **koog orchestre, langchain4j exécute** (Decision 002) : l'adaptateur
  pont `LlmProvider` (koog/codebase) → `ChatModel` (langchain4j/slider)
  matérialise la séparation.

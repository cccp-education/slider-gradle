== Objectif

US SLD-10.3 — `AsciidocContentParser` (parseur `.adoc` → `SlideContent`).
Étend le pattern `AsciidocSpeakerNoteParser` aux titres `==`, sous-titres
`===`, paragraphes, listes `* `, notes `[NOTE.speaker]`.

== Méthode

Baby-step DDD/TDD — RED → GREEN → REFACTOR. Unit tests purs (zéro Gradle,
zéro Playwright). English only (code, commentaires, noms de tests).

== Livrables

=== Domaine `slider.content` (2 nouveaux fichiers)

. `SlideContent.kt` (49l) — aggregate root (title, subtitles, paragraphs,
  lists, speakerNote). Validations `require` : title non-blank, subtitles/
  paragraphs/items non-blank, lists non-empty, speakerNote non-blank si
  présent. Helpers `hasSpeakerNote()`, `isEmpty()`.

. `AsciidocContentParser.kt` (205l) — parseur ligne par ligne `parseDeck
  (adocContent): List<SlideContent>`. Reconnaît :
  - `== Title` → nouvelle slide
  - `=== Subtitle` → sous-titre
  - `* item` → item de liste à puces
  - `[NOTE.speaker]` + `--` bloc → note orateur
  - paragraphes = blocs de lignes non-structurales
  - ignore : `= Title` (header doc), `:key: value` (attributs),
    `[.slide,...]` (attribute lists), `//` (commentaires), ligne auteur

=== 2. GREEN — Code de production (3 fichiers, domaine slider.pipeline)

Création de 3 fichiers prod purs dans le domaine `slider.pipeline` :

- `DeckPromptBuilder.kt` (25l) — port (interface) construisant les prompts
  LLM depuis le `DeckState` courant. 2 méthodes : `buildProposePrompt`
  (propose-context) + `buildGeneratePrompt` (generate-deck). Port gardé
  séparé du graphe pour tester avec stub déterministe sans dépendre de
  `slider.ai.AssistantManager.PromptManager` ni Gradle.

- `DeckLlm.kt` (20l) — port (interface) consommé par `DeckPipelineGraph`.
  2 méthodes synchrones `propose(prompt): String` + `generate(prompt):
  String`. Synchrone (pas suspend) pour garder le domaine pur et testable
  avec plain fake — l'adaptateur `suspend → blocking` vit hors domaine
  (`slider.ai` adapter sur codebase `LlmProvider`).

- `DeckPipelineGraph.kt` (115l) — graphe koog `strategy<DeckState,
  DeckState>` + méthode `execute` séquentielle. Pattern référence :
  `codebase.koog.KoogAugmentedContextGraph` (pattern hybride graphe koog
  pour topologie + execute() séquentiel avec try/catch par nœud).

  *Graphe koog* (DSL `strategy`):
  - 3 nœuds : `proposeContext`, `validateContext`, `generateDeck`
  - Edges conditionnels :
    - nodeStart → proposeContext (toujours)
    - proposeContext → validateContext (toujours)
    - validateContext → generateDeck onCondition { it.contextValid }
    - validateContext → nodeFinish onCondition { !it.contextValid }
    - generateDeck → nodeFinish (toujours)
  - `asMermaidDiagram()` via `runBlocking`

  *execute(initialState)* séquentiel (pattern KoogAugmentedContextGraph):
  1. proposeContextNode — `promptBuilder.buildProposePrompt(state)` →
     `llm.propose(prompt)` → state.copy(deckContextJson, CONTEXT_PROPOSED).
     require(json non-blank). try/catch → FAILED + error.
  2. validateContextNode — `DeckContextValidator.validate(json)` →
     Valid: copy(contextValid=true, CONTEXT_VALIDATED) ;
     Invalid: copy(validationError, error, FAILED).
  3. generateDeckNode — `promptBuilder.buildGeneratePrompt(state)` →
     `llm.generate(prompt)` → state.copy(deckAdoc, DECK_GENERATED).
     require(deckAdoc non-blank). try/catch → FAILED + error.

  Slf4j logger, ToolSelectionStrategy.NONE, name="deck-pipeline".

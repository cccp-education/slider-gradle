== Rappels méthodologiques

- Baby-step TDD : RED (test échoue) → GREEN (implé min) → REFACTOR
  (extraction + délégation thin adapter)
- 3 niveaux tests/US : unit (domaine pur, zéro Gradle) → functional
  (GradleTestKit end-to-end) → cucumber (BDD feature)
- English only : code, Gherkin, commentaires — pas de français
- Domaine DDD = value objects purs (zéro dépendance Gradle) + adapter Gradle
  thin qui délègue
- Pas de `@TempDir` JUnit dans steps Cucumber (non injecté) →
  `Files.createTempDirectory` à la place
- Shadowing `command` local vs `NpxTask.command` — toujours nommer les
  variables locales différemment des propriétés du receiver

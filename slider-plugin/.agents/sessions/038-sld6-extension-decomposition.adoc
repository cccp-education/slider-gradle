=== Domaine DDD `slider.extension` (nouveau, 3 fichiers, ~110 lignes)

  Reveal.js (version gem + organisation/repo/tag GitHub template). Defaults

  tag "5.2.1" (pin en vigueur depuis SLD-1). Validation non-blanc sur les 4
  champs. Pure — zéro Gradle.

  injection Gradle. Contrat API public préservé.
- `SliderExtensionRegistrar.kt` (53 lignes) — object orchestrateur Gradle.
  `configure(project, pin)` enregistre la DSL + pin Reveal.js. Méthodes
  publiques `registerSliderExtension(project)` et `pinRevealJsTemplate(project,
  pin)` (utiles pour tests). Dépend de `RevealJSExtension` (AsciidoctorJ) et
  `GROUP_TASK_SLIDER` (constant publique `slider.Slides.RevealJsSlides`).

=== `SliderManager.Extensions` → thin adapter

Avant (14 lignes de logique inline) :
----
object Extensions {
    internal fun Project.configureExtensions() {
        extensions.create(GROUP_TASK_SLIDER, SliderExtension::class.java)
        extensions.getByType(RevealJSExtension::class.java).apply {
            version = "5.2.0"
            templateGitHub { gh -> gh.setOrganisation("hakimel"); ... }
        }
    }
}
----

Après (thin adapter, 12 lignes) :
----
object Extensions {
    internal fun Project.configureExtensions() =
        slider.extension.SliderExtensionRegistrar.configure(this)
}
----

- `import slider.SliderPlugin.SliderExtension` (ligne 10)

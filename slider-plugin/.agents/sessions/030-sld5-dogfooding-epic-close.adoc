== Décisions techniques

. `ensureRtlDirection` dans `DeckTranslator` (domain service) plutôt que dans
  l'adaptateur LLM — la direction RTL est une propriété de la langue cible,
  pas une préoccupation de l'infrastructure LLM. Le domaine garantit la
  cohérence post-traduction.
. Le plugin asciidoctorRevealJs configure RTL via `-Planguage=ar|ur`
  (`RevealRtlResolver` + `setRightToLeft(true)`), pas via l'attribut AsciiDoc
  `:revealjs_direction:`. L'attribut est documenté pour les decks sources mais
  le rendu HTML RTL dépend du flag Gradle.
. Le dogfooding utilise un projet consumer temporaire (`/tmp/opencode/slider-dogfood`)
  avec `mavenLocal()` pour appliquer le plugin `education.cccp.slider:0.0.9` —
  le plugin n'est pas auto-appliqué au sous-projet `:slider`.

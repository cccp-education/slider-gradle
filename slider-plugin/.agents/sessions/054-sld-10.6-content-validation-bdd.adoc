= Session 054 — SLD-10.6 Slide Content Validation BDD (EPIC SLD-10 TERMINÉ)
:date: 2026-08-05
:session: 054

== Objectif

Implémentation de l'US SLD-10.6 (Cucumber
`24_slide_content_validation.feature`) — BDD end-to-end couvrant les deux
strategies d'assertion du domaine `slider.content` :

. **Validation a priori** — `ContentSlideAssertion.assertAll(SlideContent,
  SlideLayout)` : estimation depuis le `.adoc` parsé (avant rendu).
. **Validation a posteriori** — `ContentRenderAssertion.assertAll(
  ContentRenderData)` : mesure depuis le DOM rendu (snapshot DTO).

Les deux strategies partagent les 4 codes de `ContentAssertionCode`
(P0_OVERFLOW, P0_MISSING_NOTES, P1_FONT_SIZE, P1_CONTRAST) et le sealed
`ContentAssertionResult` (Passed / Failed).

== Méthode

Baby-step DDD/TDD/BDD, 3 niveaux tests/US (unit → functional → cucumber),
RED → GREEN → REFACTOR. English only (code, Gherkin, commentaires, noms de
tests). Pattern de référence : `10_rtl_visual_validation.feature` +
`RtlVisualValidationSteps.kt` (S-021) — build pure value objects → assertAll
→ assert on sealed result.

== Décisions architecturales

. **A priori et a posteriori coexistent dans la même feature**. Justification
  : les deux strategies partagent les 4 codes de `ContentAssertionCode`. La
  feature documente cette coexistence dans son preamble et teste les deux
  independamment puis en cross-validation (scénario 11).

. **Snapshot DTO `ContentRenderData` construit directement dans les steps**
  (pas de Playwright réel). Justification : le runner Cucumber exclude
  `@integration` (Ollama) — les scénarios BDD testent la logique pure
  (assertion sur snapshot), pas l'extraction Playwright. Le functional test
  Playwright (S-053) couvre deja l'extraction réelle. Le scenario
  `a text block at x ...` ajoute un `TextBlock` au snapshot via `copy()`.

. **11 scénarios** (5 a priori + 5 a posteriori + 1 cross-validation).
  Justification : couvrir les 4 codes × 2 strategies + le cas nominal Passed
  × 2 + la cross-validation. Pas de scénario `@integration` (Playwright réel)
  — laissé au functional test S-053.

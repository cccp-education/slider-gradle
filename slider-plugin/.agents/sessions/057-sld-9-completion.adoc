== Décisions architecture

. *Clés techniques non traduites* : les 10 `task.group.*` (build, generate,
  info, setup, verify, deploy, slider, translator, collect, slider-ai) sont
  des identifiants stables de groupe Gradle — identiques cross-langue par
  design. Exclus des tests `assertNotEquals`. Exception : `task.group.translator`
  PARTIAL (FR=traducteur, autres=translator) — inclus uniquement dans
  MessagesFrTranslationTest.
. *Placeholders purs non traduits* : `task.translateDeck.translated/failed/summary`
  sont des formats `{0} -> {1}`, `{0} — {1}`, `{0}` — identiques cross-langue
  car purement structurels. Exclus des tests de traduction.
. *Step deduplication Cucumber* : `SliderMessagesResolutionSteps` utilise
  `the resolved message should contain` (préfixe) pour éviter collision avec
  `AssistantManagerI18nSteps` (`the message should contain`).
